# 隐私政策

**最后更新日期：2026年3月23日**

## 引言

欢迎使用 Riverpod Mode 应用程序（以下简称"本应用"）。我们非常重视您的隐私保护，并将个人信息保护作为我们的首要任务。本隐私政策旨在向您说明我们如何收集、使用、存储和保护您的个人信息。

请在使用本应用前仔细阅读本隐私政策。使用本应用即表示您同意本隐私政策的条款。

## 1. 信息收集

### 1.1 我们收集的信息

本应用可能会收集以下类型的信息：

**自动收集的信息：**
- 设备信息（设备型号、操作系统版本）
- 应用使用统计数据
- 崩溃日志和性能数据

**您提供的信息：**
- 应用设置偏好
- 主题配置数据

### 1.2 信息收集方式

- **自动收集：** 当您使用本应用时，某些信息会自动收集
- **用户输入：** 您在应用中主动输入或配置的信息

## 2. 信息使用

我们收集的信息将用于以下目的：

1. **提供服务：** 确保应用正常运行和功能实现
2. **改进体验：** 分析用户行为以改进产品功能和用户体验
3. **技术支持：** 诊断技术问题并提供支持
4. **安全保障：** 检测和防止欺诈或其他非法活动

## 3. 信息存储与安全

### 3.1 本地存储

本应用收集的信息主要存储在您的设备本地，包括：
- SharedPreferences
- MMKV 存储
- 本地数据库

### 3.2 安全措施

我们采取以下安全措施保护您的信息：
- 数据加密存储
- 安全的网络传输
- 定期安全审计

## 4. 信息共享

我们不会将您的个人信息出售、交易或以其他方式转让给第三方，除非：

1. 获得您的明确同意
2. 法律法规要求
3. 保护我们或用户的权利、财产或安全

## 5. 您的权利

您对您的个人信息享有以下权利：

- **访问权：** 您有权了解我们收集了哪些关于您的信息
- **更正权：** 您有权要求更正不准确的信息
- **删除权：** 您有权要求删除您的个人信息
- **撤回同意权：** 您有权撤回之前给予的同意

## 6. 儿童隐私

本应用不面向13岁以下的儿童。我们不会故意收集儿童的个人信息。如果您发现您的孩子向我们提供了个人信息，请联系我们。

## 7. 隐私政策变更

我们可能会不时更新本隐私政策。更新后的政策将在本页面发布，建议您定期查看。

## 8. 联系我们

如果您对本隐私政策有任何疑问或建议，请通过以下方式联系我们：

- **应用名称：** Riverpod Mode
- **项目地址：** GitHub 开源项目
